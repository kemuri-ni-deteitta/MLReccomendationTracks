# Music Track Recommendation System

Курсовая работа по дисциплине **«Машинное обучение»**, выполненная в МГТУ «СТАНКИН».

Проект представляет собой рекомендательную систему музыкальных треков, которая использует аудиоэмбеддинги, поиск по векторному сходству, классификацию жанров и гибридное ранжирование рекомендаций.

Основой системы является предобученная мультимодальная модель **CLAP (Contrastive Language-Audio Pretraining)**, преобразующая аудио и текстовые запросы в общее векторное пространство. Благодаря этому система может находить музыкальные композиции, близкие к запросу пользователя по смыслу и музыкальному содержанию.

---

## Основные возможности

В проекте реализованы:

- обработка и подготовка аудиофайлов;
- извлечение признаков из аудио с помощью CLAP;
- формирование 512-мерных аудиоэмбеддингов;
- классификация музыкальных жанров;
- поиск похожих треков по cosine similarity;
- векторный поиск с использованием FAISS;
- фильтрация рекомендаций по жанру;
- дополнительное ранжирование с использованием co-occurrence matrix;
- гибридная схема формирования рекомендаций;
- веб-интерфейс на Gradio;
- прослушивание рекомендованных треков непосредственно в интерфейсе.

# Подготовка аудиоданных

Первый этап работы заключается в предварительной обработке музыкальных композиций.

Основная логика находится в:

```text
notebooks/01_audio_embedding_clap.ipynb
```

Для загрузки аудио используется `torchaudio`.

## Преобразование в mono

Аудиофайлы приводятся к одному каналу:

```python
waveform = waveform.mean(dim=0).unsqueeze(0)
```

Это позволяет передавать данные в модель в едином формате вне зависимости от исходного числа каналов.

---

## Resampling

Все композиции приводятся к частоте:

```text
48 000 Hz
```

Для этого используется:

```python
torchaudio.transforms.Resample(
    orig_freq=sr,
    new_freq=48000
)
```

---

## Ограничение продолжительности

Для обработки используется фрагмент продолжительностью до 30 секунд.

При частоте 48 kHz это соответствует:

```text
48 000 × 30 = 1 440 000 samples
```

Такой подход позволяет унифицировать входные данные и сократить вычислительную нагрузку.

---

# CLAP

Основой системы является модель:

```text
laion/clap-htsat-unfused
```

Она загружается через библиотеку Hugging Face Transformers:

```python
from transformers import ClapProcessor, ClapModel
```

CLAP расшифровывается как:

**Contrastive Language-Audio Pretraining**

Модель обучена сопоставлять текстовые и аудиоданные в общем векторном пространстве.

Благодаря этому можно сравнивать не только два аудиофайла, но и текстовый запрос с музыкальной композицией.

```text
Text Request
     |
     v
 CLAP Text Encoder
     |
     v
   Vector
     |
     | similarity
     |
   Vector
     ^
     |
 CLAP Audio Encoder
     ^
     |
 Audio Track
```

---

# Audio Embeddings

Для каждой музыкальной композиции формируется вектор признаков:

```python
model.get_audio_features(...)
```

На выходе получается embedding размерностью:

```text
512
```

Условно музыкальный трек представляется следующим образом:

```text
track.mp3

    ↓ CLAP

[0.018, -0.273, 0.117, ..., 0.081]
```

Полученные векторы сохраняются в NumPy-файлы:

```text
audio_vectors.npy
audio_filenames.npy
```

Такой формат позволяет выполнять дальнейшие ML-операции без повторной обработки исходного MP3-файла.

# Поиск похожих треков

Основная логика рекомендательной системы находится в:

```text
src/recommender.py
```

Для быстрого поиска ближайших треков используется библиотека **FAISS**.

Перед созданием индекса embeddings нормализуются:

```python
faiss.normalize_L2(self.embeddings)
```

После чего создается индекс:

```python
faiss.IndexFlatIP(self.dim)
```

При использовании L2-нормализованных векторов Inner Product позволяет выполнять поиск, эквивалентный сравнению по **cosine similarity**.

# Текстовый запрос

Пользователь может указать:

```text
Artist
Song
Genre
```

Например:

```text
Artist: Radiohead
Song: Karma Police
Genre: Rock
```

Из введенных данных формируется текстовый запрос:

```text
Karma Police by Radiohead in the genre Rock
```

После этого запрос преобразуется CLAP в текстовый embedding:

```python
self.model.get_text_features(...)
```

Поскольку текстовые и аудиоэмбеддинги находятся в одном пространстве, система может искать музыкальные композиции, близкие к заданному текстовому описанию.

# Content-Based Recommendation

Основой системы является content-based подход.

```text
User Query
    |
    v
CLAP Text Embedding
    |
    v
FAISS Search
    |
    v
Nearest Audio Embeddings
    |
    v
Similar Tracks
```

FAISS сначала находит множество наиболее близких кандидатов.

После этого:

- выполняется фильтрация по жанру;
- исходный трек исключается из результата;
- формируется список наиболее близких композиций.

---

# Co-occurrence Matrix

Дополнительная матрица связей между композициями строится в:

```text
notebooks/03_build_co_matrix.ipynb
```

Создается матрица:

```text
N × N
```

где каждый элемент характеризует связь между двумя композициями.

В текущей реализации связи формируются на основе общих характеристик треков:

- одинакового исполнителя;
- одинакового жанра.

Для связанных композиций значение увеличивается:

```python
co[i, j] += 1
```

После этого строки матрицы нормализуются.

Важно отметить, что текущая реализация не использует реальные пользовательские истории прослушиваний. Поэтому co-occurrence matrix является дополнительным metadata-based сигналом, а не классическим collaborative filtering на пользовательских действиях.

---

# Hybrid Recommendation

Финальное ранжирование объединяет два сигнала:

1. сходство CLAP embeddings;
2. значение co-occurrence matrix.

Вес контентной составляющей определяется параметром:

```python
alpha = 0.7
```

Итоговая оценка рассчитывается по принципу:

```text
Final Score =
    0.7 × Content Similarity
  + 0.3 × Co-occurrence Score
```

То есть основная роль остается у сходства музыкального контента, а дополнительная матрица используется для корректировки ранжирования.

---

# Формирование рекомендаций

Система по умолчанию возвращает до 10 музыкальных композиций.

Результат состоит из комбинации:

```text
Content-Based Recommendations
+
Hybrid Recommendations
```

Повторяющиеся элементы исключаются.

В результате пользователь получает набор различных треков, максимально соответствующих введенному запросу.
